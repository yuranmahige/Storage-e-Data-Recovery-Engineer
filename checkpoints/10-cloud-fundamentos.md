# Cloud Fundamentos

## Conceitos
- [ ] Sabe a diferença entre IaaS, PaaS, SaaS
- [ ] Sabe o que é FaaS (Function as a Service)
- [ ] Sabe a diferença entre public, private, hybrid cloud
- [ ] Sabe o que é multi-cloud vs. hybrid
- [ ] Sabe o que é edge computing
- [ ] Sabe o que é serverless (conceito, não só Lambda)
- [ ] Sabe o que é "pay-as-you-go" vs. reserved vs. spot
- [ ] Sabe o que é TCO (Total Cost of Ownership)
- [ ] Sabe o que é SLA (Service Level Agreement)
- [ ] Sabe o que é RTO e RPO (Disaster Recovery)
  - RTO: tempo máximo para restaurar
  - RPO: dados máximos que pode perder (em tempo)
