# Linux Básico (Ubuntu)

## Terminal
- [ ] Navega no terminal sem GUI (cd, ls, pwd, mkdir, rm, cp, mv)
- [ ] Sabe usar tab completion e histórico (↑↓)
- [ ] Sabe o que é pipe (`|`) e redirecionamento (`>`, `>>`)
- [ ] Sabe usar `grep`, `head`, `tail`, `wc`
- [ ] Sabe o que é `sudo` e permissões (rwx)
- [ ] Sabe usar `chmod`, `chown`
- [ ] Sabe o que é um script shell básico

## Sistema
- [ ] Sabe o que é o sistema de arquivos Linux (`/`, `/home`, `/etc`, `/var`, `/dev`)
- [ ] Sabe o que é `fstab`
- [ ] Sabe o que é um processo (`ps`, `top`, `kill`)
- [ ] Sabe o que é um serviço (`systemctl`)
- [ ] Sabe o que é um log (`journalctl`, `/var/log`)
- [ ] Sabe o que é um usuário/grupo
- [ ] Sabe o que é um link simbólico (`ln -s`)

## Instalação e VMs
- [ ] Sabe instalar pacotes (`apt`)
- [ ] Sabe criar e gerenciar VMs (VirtualBox / KVM/QEMU)
- [ ] Sabe montar uma VM com disco virtual e testar comandos nela
- [ ] Sabe fazer snapshot de VM (para "quebrar" sem medo)
